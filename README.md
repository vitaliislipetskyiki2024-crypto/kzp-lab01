# Лабораторна робота №1 — Кінотеатр

## Призначення програми

Програма призначена для обробки даних про фільми в кінотеатрі.

Вона зчитує записи з CSV-файлу, перевіряє їх правильність та для правильних записів обчислює:
- кількість правильних записів;
- загальний дохід;
- середню ціну квитка;
- максимальну кількість проданих квитків.

Некоректні записи пропускаються та виводяться на екран.

## Формат вхідних даних

Вхідні дані зберігаються у файлі:

`data/input.csv`

```text
film;hall;ticketPrice;sold;durationMin
