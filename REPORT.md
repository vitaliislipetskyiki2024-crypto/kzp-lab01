# Звіт до лабораторної роботи №1

## Тема

Розробка програми для обробки даних про кінотеатр.

## Варіант

**Варіант 19 — Кінотеатр.**

## Мета роботи

Метою лабораторної роботи є розробка консольної програми мовою Java для
зчитування, перевірки та обробки даних про фільми в кінотеатрі.

Під час виконання роботи було налаштовано Maven-проєкт, додано модульні
тести JUnit 5, статичний аналізатор SpotBugs, Maven Wrapper та формування
виконуваного JAR-файлу.

## Постановка задачі

Програма повинна зчитувати дані про фільми з CSV-файлу.
