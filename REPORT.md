# Звіт до лабораторної роботи №1

## 1. Тема, номер і варіант
* **Лабораторна робота:** №1
* **Тема:** Розробка програми для обробки даних про кінотеатр
* **Предметна область:** Кінотеатр
* **Варіант:** №19
* **Операційна система:** Windows 10

## 2. Мета роботи
Метою лабораторної роботи є розробка консольної програми мовою Java для зчитування, перевірки та обробки даних про фільми в кінотеатрі.

**Досягнуті результати:**
Налаштовано Maven-проєкт, додано модульні тести JUnit 5, статичний аналізатор SpotBugs, Maven Wrapper та реалізовано формування виконуваного JAR-файлу.

## 3. Постановка задачі
Програма повинна зчитувати дані про фільми з CSV-файлу `data/input.csv`.

**Формат одного запису:**
```text
film;hall;ticketPrice;sold;durationMin

Чотири розрахункові показники варіанта 19:
Загальний виторг кінотеатру (сума ticketPrice * sold).
Середня тривалість фільму (середнє значення durationMin).
Найпопулярніший фільм (фільм з максимальним значенням sold).
Загальна кількість відвідувачів (сума всіх sold).

## 4. Структура програми
Структура файлів і пакетів (ua.lpnu.kzp):
data/input.csv — файл із вхідними даними.
Main.java — точка входу (запускає програму).
FileReport.java — читає CSV-файл, рахує 4 показники та формує звіт.
MainTest.java — тести (JUnit 5) для перевірки роботи.
Потік даних (від входу до звіту):
Вхід: Файл data/input.csv із текстом.
Обробка: FileReport.java зчитує файл рядок за рядком, розбиває дані по ; та обчислює 4 показники варіанта.

## 5. Інфраструктура
Система збірки: Apache Maven із використанням Maven Wrapper (./mvnw).
Залежності (pom.xml):
JUnit 5 — для написання та виконання модульних тестів у MainTest.java.
SpotBugs — для статичного аналізу коду на наявність багів та помилок.
Пакування: Налаштовано створення виконуваного .jar файлу в директорії target/.

11. Відповіді на контрольні питання 
pom.xml — налаштування Maven: залежності, Java, плагіни, збірка.
test — запускає тести; package — створює JAR; verify — виконує додаткові перевірки, наприклад SpotBugs.
Maven Wrapper — дозволяє запускати Maven без ручного встановлення Maven.
main — точка входу в Java-програму.
Примітиви — прості значення (int, double); String — об'єкт для тексту.
double потрібен, щоб не втратити дробову частину при діленні.
Integer.parseInt("abc") викликає NumberFormatException.
Помилки не можна приховувати, бо користувач має знати про неправильні дані.
split(";", -1) зберігає порожнє останнє поле.
Path.of — кросплатформений спосіб роботи зі шляхами.
UTF_8 забезпечує правильне читання українських символів.
%n використовує правильний перенос рядка для конкретної ОС.
Перевіряємо 5 полів, назву, зал, ціну, продані квитки та тривалість.
Потрібні тести, де середнє має дробовий результат.
SpotBugs шукає потенційні помилки в коді без його виконання.
GitHub Actions автоматично запускає збірку, тести та перевірки.
Issue має містити опис помилки, кроки відтворення, очікуваний і фактичний результат.
Вказуємо, які інструменти ШІ використовували та для чого.
DevOps налаштовує інфраструктуру та CI/CD, Валідатор перевіряє правильність програми та відповідність вимогам.
